# SynthHair Project Page

Project page for **SynthHair: Leveraging MetaHumans for a High-Quality 4K Hair Matting Dataset**.

The main page (`index.html`, `static/css/site.css`, `static/js/site.js`) is plain HTML/CSS/JS without
dependencies. The privacy notice is based on the [Nerfies](https://github.com/nerfies/nerfies.github.io)
website template.

## Local preview

```bash
cd hair_matting/project_page
python -m http.server 8000
```

Then open http://localhost:8000

## Media

Everything in `static/media/` is generated by `tools/build_assets.py` from the NeurIPS visuals
(`hair_matting/neurips_visuals_claude`) and the predictions on the AI-generated portraits used in
the qualitative paper figures:

```bash
uv run python hair_matting/project_page/tools/build_assets.py
```
